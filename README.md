# 🤖 AI UX Research Agent

An AI-powered UX research agent that analyzes grocery app user reviews, identifies major UX problems, calculates affected users and percentages, and generates a structured UX research report.

## 🎯 Project Overview

UX researchers often need to analyze large amounts of user feedback to identify recurring usability problems.

This project demonstrates how an AI agent can automate part of that research workflow by:

- Reading user reviews
- Identifying UX problems
- Counting users affected by each problem
- Calculating percentages using a dedicated tool
- Providing evidence from actual reviews
- Prioritizing UX problems
- Generating and saving a final UX research report
